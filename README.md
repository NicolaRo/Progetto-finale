# PROGETTO FINALE

A clean, lightweight app with a smooth friendly UI.

Live Demo: **https://packback-greengrocery.netlify.app/login**
Hosting: **Netlify & Render ** 🚀

---

## ⚡ Tech Stack

* **React** (Vite)
* **Custom CSS** with glassmorphism effects
* **Netlify** for continuous deployment
* **Node.js + Express** handle the backend
* **MongoDB + Mongoose** handle the database
* **Axios** handle the HTTP Requests 
* **React Hooks** to take advantage from React's great potential
* **Tested with Postman** to grant a solid development also in future stages

## 📦 Deployment

The production build is automatically deployed via **Netlify**.
Live site:
👉 [https://packback-greengrocery.netlify.app/login]
